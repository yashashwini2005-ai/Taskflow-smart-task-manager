# TaskFlow — Smart Task Management App

A full-stack task management application built with **React** and **Django REST Framework**. TaskFlow helps users organize daily tasks, assign priorities, set due dates, track progress, and manage completed and pending work through a simple dashboard.

## Overview

TaskFlow was developed as a hands-on full-stack web development project to practise building a React user interface, creating REST APIs with Django, and connecting a frontend to a backend database.

The application allows users to create tasks, organize them by category and priority, mark tasks as completed, delete tasks, and track their overall progress. Task data is stored by the backend, so saved tasks remain available after refreshing the page.

## Features

- **Create tasks:** Add a task with a title, category, priority, and optional due date.
- **Task categories:** Organize tasks into Personal, Learning, Career, and Work categories.
- **Priority management:** Set each task to Low, Medium, or High priority.
- **Due dates:** Assign a due date to a task.
- **Completion tracking:** Mark tasks as completed or pending.
- **Delete tasks:** Remove tasks that are no longer needed.
- **Task filtering:** View all tasks, only pending tasks, or only completed tasks.
- **Dashboard statistics:** View total tasks, completed tasks, pending tasks, and completion percentage.
- **Persistent storage:** Save and retrieve tasks through the Django backend and database.
- **REST API integration:** Use Axios to send requests between the React frontend and Django backend.

## How It Works

1. The user interacts with the TaskFlow dashboard built in React.
2. When a task is created, React sends a POST request using Axios to the Django REST API.
3. Django REST Framework validates the request through the task serializer.
4. Django stores the task in its database.
5. The frontend retrieves saved tasks using a GET request.
6. Task completion and deletion are handled through PATCH and DELETE requests.
7. The dashboard updates its task list and statistics to reflect changes.

## Backend API Endpoints

The backend exposes task-management endpoints under `/api/tasks/`.

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/tasks/` | Retrieve tasks |
| POST | `/api/tasks/` | Create a task |
| GET | `/api/tasks/{id}/` | Retrieve one task |
| PATCH | `/api/tasks/{id}/` | Update task fields |
| PUT | `/api/tasks/{id}/` | Replace a task |
| DELETE | `/api/tasks/{id}/` | Delete a task |

These endpoints are provided by Django REST Framework's `ModelViewSet` and router.

## Task Data Model

Each task contains the following fields:

- `id`: Unique identifier generated by Django.
- `title`: Task name.
- `category`: Task category; defaults to Personal.
- `priority`: Low, Medium, or High.
- `due_date`: Optional task deadline.
- `completed`: Boolean value indicating whether the task is complete.
- `created_at`: Date and time when the task was created.

## Getting Started

### Prerequisites

Install the following tools:

- Python
- Node.js and npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/yashashwini2005-ai/Taskflow-smart-task-manager.git
cd Taskflow-smart-task-manager
```



### 2. Set up the Django backend

Open a terminal in the project root:

```bash
cd backend
python -m venv venv
```

Activate the virtual environment.

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```cmd
venv\Scripts\activate.bat
```

Install backend dependencies:

```bash
python -m pip install django djangorestframework django-cors-headers
```

If a `requirements.txt` file is included, you can install the recorded dependencies instead:

```bash
python -m pip install -r requirements.txt
```

Apply database migrations:

```bash
python manage.py makemigrations
python manage.py migrate
```

Start the backend:

```bash
python manage.py runserver
```

The backend will be available at `http://127.0.0.1:8000/`.

The task API is available at `http://127.0.0.1:8000/api/tasks/`.

### 3. Set up the React frontend

Open a second terminal and navigate to the frontend folder:

```bash
cd frontend
npm install
npm install axios
```

Start the frontend:

```bash
npm run dev
```

Open the local URL displayed by Vite, usually `http://localhost:5173/`.

Keep both development servers running while using the application.

## Development Configuration

During local development, the frontend Axios client connects to the Django API at:

```javascript
baseURL: 'http://127.0.0.1:8000/api/'
```

Django CORS configuration should allow the frontend origin:

```python
CORS_ALLOWED_ORIGINS = [
    "http://localhost:5173",
]
```

These settings are intended for local development. Update the API base URL and allowed origins when deploying the application.
